# ConnectSphere Frontend

## Overview

React + TypeScript frontend with Tailwind CSS dark romantic theme.

## Quick Start

```bash
npm install
npm run dev
```

Frontend runs at: http://localhost:5173

## Project Structure

```
src/
├── pages/              # Page components
├── components/         # Reusable components
├── services/           # API services
├── hooks/              # Custom hooks
├── context/            # React context
├── styles/             # Global styles
└── App.tsx             # Main app
```

## Features

✅ Responsive dark theme
✅ Tailwind CSS styling
✅ Real-time chat UI
✅ Profile management
✅ Discover/swiping interface
✅ Travel planning
✅ Matches dashboard

## Technologies

- React 18
- TypeScript
- Tailwind CSS
- Framer Motion (animations)
- React Router
- Axios (HTTP)
- Supabase (auth/db)
